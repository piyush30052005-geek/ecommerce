# 🛒 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview

The **E-Commerce Sales Analysis Dashboard** is an end-to-end data analytics project developed to analyze e-commerce sales data and transform raw data into meaningful business insights.

The project covers the complete data analytics workflow — from data cleaning and transformation using **Python**, data storage and analysis using **MySQL and SQL**, to interactive data visualization using **Power BI**.

To make the analysis more accessible and interactive, the final dashboard was also developed and **web-hosted using Lovable**.

The project helps analyze sales performance, profitability, orders, products, categories, cities, payment methods, and order status.

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall e-commerce sales performance.
- Calculate important business KPIs.
- Identify profitable product categories.
- Analyze monthly sales trends.
- Understand sales performance by city.
- Analyze different payment methods.
- Understand order status distribution.
- Identify high-performing products.
- Create an interactive and user-friendly dashboard.
- Convert raw data into actionable business insights.
